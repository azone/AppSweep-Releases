# AppSweep

AppSweep helps you review an app and its associated files before moving them to
the Trash.

Download the latest beta for your Mac from the [Releases page](https://github.com/azone/AppSweep-Releases/releases):

- **Apple Silicon** for Macs with an M-series chip
- **Intel** for Macs with an Intel processor

Requires macOS 13 or later. Learn more at [appsweep.firestudio.dev](https://appsweep.firestudio.dev/).
